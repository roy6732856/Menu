# Project Image Guidelines

## Image Requirements

- **Recommended Resolution**: 1080x1350 pixels
- **Aspect Ratio**: 4:5
- **Format**: JPG or PNG
- **Max File Size**: Recommend keeping under 500KB for optimal loading

## Why These Dimensions?

- 1080x1350 pixels is the optimal size for:
  - Social media sharing
  - Project previews
  - Responsive design across different devices
  - Consistent layout presentation

## Tips for Project Images

1. Use high-quality, relevant screenshots or previews of your project
2. Ensure the image is clear and well-lit
3. Compress images before adding them to maintain fast loading times
4. Keep the main focus of the image in the center

## File Naming Convention

- Use lowercase letters
- Replace spaces with hyphens
- Example: `my-project-name.jpg`



## 圖片要求

- **建議解析度**：1080x1350 像素
- **長寬比**：4:5
- **格式**：JPG 或 PNG
- **最大檔案大小**：建議保持在 500KB 以下以獲得最佳載入效果

## 為什麼選擇這些尺寸？

- 1080x1350 像素是以下用途的最佳尺寸：
  - 社群媒體分享
  - 專案預覽
  - 跨裝置的響應式設計
  - 一致的版面呈現

## 專案圖片注意事項

1. 使用高品質、相關的專案截圖或預覽
2. 確保圖片清晰且光線充足
3. 在添加圖片前進行壓縮以維持快速載入時間
4. 將圖片的主要焦點保持在中央

## 檔案命名規則

- 使用小寫字母
- 空格以連字符號（-）取代
- 範例：`my-project-name.jpg`
